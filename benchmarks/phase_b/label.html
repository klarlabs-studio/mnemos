Keys (when not typing)

  
n/p next / previous item · N next item with work left ·
     1-4 stage tabs · d mark this stage done / not done ·
     Esc leave a text field · ? this help

  
Extraction: e edit gold claims (one per line) · r reveal the
     extracted claims (only after writing your gold claims; this cannot be undone for the item).

  
Relations: j/k move · s supports ·
     c contradicts · > first supersedes second ·
     < second supersedes first · x no relation · a add a missing edge

  
Truth: j/k move · t true · f false ·
     u cannot tell

  
Questions: a add a question.
